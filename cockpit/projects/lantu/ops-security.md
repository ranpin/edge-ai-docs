# 7. 运维及安全

## 1. 设备安装

接线、水冷安装、usb 云机挂载。

## 2. 系统升级

PCAT 刷机、OTA 升级。

## 3. OTA 升级（未做）

提供所有模型文件的 md5 值，升级前进行计算匹配，得到不同的文件，下载对应的资源包，存放在固定位置，读取替换。

## 4. 模型加密（未做）

- 写一个打包工具（负责将 bin 打包成 img，创建一个稍微大一点的文件，再利用加密算法）
- 写一个 load 进程
  - 负责加载 img 文件，进行 mount，得到 bin 文件，并且控制访问权限，shell 不可见
  - 负责结束时，umount 上述 img 镜像
- Vlm 推理进程可以通过 **load 进程挂载后的固定路径** 访问上述 bin 文件（配合 SELinux/文件权限，仅 VLM 进程域可读、shell 域不可见）；**或** 由 load 进程通过 **fd（文件描述符）经 IPC 传递** 给 VLM 进程，使 bin 路径完全不暴露（更安全，但需进程间 fd 传递机制）。〔设计待定：二选一需结合量产权限模型确认——固定路径方案实现简单但依赖 SELinux 域隔离，fd 传递方案隔离性更强但需 load 与 VLM 进程建立 IPC 通道〕
